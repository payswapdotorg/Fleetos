# FleetOS

FleetOS is the operating system for an organization's physical computing fleet.

It continuously understands devices, workloads, software, connectivity, contracts, maintenance, security and fulfillment. The product works for fleets purchased through Fleet and for existing customer-owned fleets that install FleetOS software/connectors.

Core loop:
observe -> model -> diagnose -> plan -> authorize -> act -> verify -> learn

Product surfaces:
- Device Doctor
- Security Doctor
- Contract Guardian
- Fleet Actions
- Workload Intelligence
- Procurement Exchange
- Software Exchange
- Maintenance Exchange
- Connectivity Orchestration
- Recovery / Find My Device
- Arena-powered learning
- Aurum-powered communication
