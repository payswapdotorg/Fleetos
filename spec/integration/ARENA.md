# Arena Integration Contract

FleetOS submits authorized learning/evaluation cases. Arena develops, evaluates and certifies reusable capabilities.

Case:
problem class, normalized observations, context, action history, outcome, evaluation labels, tenant policy and redaction/de-identification state.

Adoption:
capability ID/version, Arena certification reference, FleetOS compatibility, evaluation-suite revision, rollout policy, cohort and rollback version.

FleetOS never treats an uncertified model output as action permission.
