# FleetOS Product Requirements

PR-001 SaaS-only onboarding: enroll an existing fleet without buying hardware from Fleet.
PR-002 Device Doctor: observe devices, detect anomalies, diagnose likely causes, recommend treatment and schedule maintenance.
PR-003 Security Doctor: observe security posture, integrate with security tooling and automate permitted remediation.
PR-004 Contract Guardian: turn obligations into enforceable controls over data, software, printers, network and destinations.
PR-005 Workload planning: map workload requirements to devices, software, connectivity and lifecycle policy.
PR-006 Software subscriptions: identify required seats, reuse entitlements where permitted and procure missing subscriptions.
PR-007 Procurement exchange: match demand to local vendors and use deadlines for compatible aggregation/discount discovery.
PR-008 Maintenance exchange: route predicted maintenance to local repair, warranty or service providers.
PR-009 Fleet connectivity: obtain fleet connectivity outcomes through ADCOS.
PR-010 Fleet actions: operate groups; example selected people + document + Print -> each person's approved printer receives the job.
PR-011 Recovery: find, lock, protect, recover, replace and restore lost devices.
PR-012 Learning: turn outcomes into evaluation cases and adopt certified capabilities.
PR-013 Communication: deliver notifications, approvals and briefings through Aurum.
PR-014 Explainability: diagnoses and actions expose evidence, version and audit trail.
PR-015 Privacy: least-privilege, purpose-bound telemetry and explicit BYOD boundaries.
PR-016 Resilience: local cached policy/actions continue where supported if SaaS control plane is unavailable.
