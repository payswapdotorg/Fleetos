# Device Twin Contract

Identity:
device ID, tenant ID, ownership type, assigned person/team, manufacturer, model and asset/serial references.

Capability:
CPU/GPU/RAM/storage, ports/peripherals, network interfaces and supported management/security capabilities.

State:
health, security, software, connectivity, location evidence, power/battery, lifecycle and maintenance.

History:
observations/events are append-only and timestamped.

Interpretation:
diagnoses, predictions, recommendations and risks are versioned with capability version, evidence references, confidence, generated time and supersession.

Privacy:
fields are purpose-tagged and policy-filterable; location, user activity and BYOD data require explicit scope.
